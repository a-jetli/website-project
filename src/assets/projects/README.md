Add screenshots or GIFs to a folder named for the project's `id` in `src/projects.js`.

Example: `src/assets/projects/rotation/01-listening-overview.webp`

Supported extensions: `.avif`, `.gif`, `.jpeg`, `.jpg`, `.png`, `.webp`.
Files appear in filename order on both Home and Projects. Use descriptive filenames, since the viewer uses them as image labels. Rebuild the site after adding files.
