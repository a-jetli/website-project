Agentic RAG Pipeline Live demo
Python · LangGraph · FastAPI · ChromaDB · OpenAI API · BM25

Before that I worked on an agentic RAG pipeline over 1000 arXiv papers spanning many topics in AI, which I personally use to learn by asking questions on new or misunderstood topics or formulas. It works on a LangGraph agent that breaks queries into subequeries, and when fetching relevant chunks it reranks and checks if a sufficient answer can be formed. If not, it tries again. You can demo it yourself at rag.ajetli.com, or read more about it under the architecture tab. You can also view every single paper used under the papers tab.

LLM Text RPG Engine
Python · OpenAI API · Pydantic · Textual

An ongoing project of mine is a presently unnamed text based RPG game where I had the idea to make an LLM act as a world builder and narrator, almost like a dungeon master. The idea was to be able to play through your own book, where narratively you were the main character but you did not dictate the state of the world beyond. However, to make this work as a full scale project I had to figure out logging and retrieval strategies. My solution uses a deterministic Python engine that owns the game state and an LLM that outputs game state alterations in an enforced structured output format, allowing the engine to receive and resolve all changes with no risk of hallucination. I'm constantly iterating on this project and you can read more about it or look through the code at the GitHub repo linked above.
